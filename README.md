# PwnHero Aion 2 Input Fix (`pwnhid`)

Minimal Windows **UMDF2 + Virtual HID Framework (VHF)** virtual keyboard/mouse driver and foreground hook bridge for **Aion 2** over Apollo, Sunshine, and Moonlight.

- **Full Guide:** [Fix Aion 2 Input Not Working on Apollo, Sunshine & Moonlight (PwnHero Blog)](https://pwnhero.com/resources/blog/aion-2-apollo-sunshine-moonlight-input-fix)
- **Download:** Grab `PwnHero-Aion2-Fix-v1.0.zip` from [Releases](https://github.com/PwnHero/pwnhero-aion2-input-fix/releases).
- **Bugs & Suggestions:** Open an issue on [GitHub Issues](https://github.com/PwnHero/pwnhero-aion2-input-fix/issues).

## Quick Usage (Administrator PowerShell)
- Install: `powershell -ExecutionPolicy Bypass -File .\install.ps1`
- Uninstall: `powershell -ExecutionPolicy Bypass -File .\uninstall.ps1`
